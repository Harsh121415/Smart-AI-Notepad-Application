# SmartNotepad 📝

SmartNotepad is an Android note-taking application built using Kotlin and Jetpack Compose. It provides a simple way to create, edit, archive, restore, and manage notes.

## Features
- Create and edit notes
- View and manage saved notes
- Archive and restore notes
- Store notes locally using Room Database
- Clean user interface

## Tech Stack
- Kotlin
- Jetpack Compose
- Room Database
- MVVM Architecture
- Android Studio

## Getting Started
1. Clone this repository.
2. Open the project in Android Studio.
3. Sync Gradle dependencies.
4. Run the app on an emulator or Android device.
